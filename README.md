# Trojan Virus Detection using Graph Convolutional Networks (GCN)

Este proyecto implementa y explica un modelo de detección de virus troyano utilizando **Redes Neuronales Convolucionales sobre Grafos (GCN)**. Está basado en el paper:

> **"Trojan Virus Detection and Classification Based on Graph Convolutional Neural Network Algorithm"**  
> REN et al., Journal of Industrial Engineering and Applied Science, 2025

---

## Objetivo

Detectar y clasificar tráfico de red como **benigno** o **troyano** utilizando un modelo de aprendizaje profundo con GCN. Se construyen grafos a partir de las características del tráfico mediante K-Nearest Neighbors (KNN) y se entrena un modelo para distinguir patrones maliciosos.
